# Fool's Playground

Scenario-Driven Cybersecurity Capture The Flag (CTF) Play Box

## Project

Fool's Playground is a scenario-driven cybersecurity CTF designed for the
IE3132 – Penetration Testing module.

Participants take the role of cybersecurity investigators responding to a
simulated compromise created by an attacker known as The Fool.

The investigation progresses through six interconnected cybersecurity
challenges.

## Challenge Sequence

1. FP-01 — The Invitation
2. FP-02 — The Fool's Cipher
3. FP-03 — The Locked Door
4. FP-04 — The Forgotten Evidence
5. FP-05 — The Silent Network
6. FP-06 — The Fool's Domain

## Cybersecurity Domains

## Platform

The project uses CTFd as the central CTF platform for:

- User management
- Challenge management
- Flag validation
- Scoring
- Challenge progression
- Hints
- Challenge files
